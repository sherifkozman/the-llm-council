# 0.8.5 Security Maintenance

Date: 2026-10-23. This record describes the tested candidate. The GitHub release
will carry the final merge, publication and PyPI artifact receipts after those
steps succeed. It is not a claim of a global installation or service restart.

## Automatic Evidence Containment

Before this fix, a repository file symlink or a top-level evidence search-root
symlink could make automatic evidence collection read an owner-readable file
outside the selected repository. Matching lines entered the provider-bound draft
prompt. This was reproduced with harmless temporary markers and a locally
intercepted request, not real secrets or an external disclosure. The reproduction
does not show that an attacker receives the provider's copy of the data.

Discovery filters resolved targets to the canonical repository root. More
importantly, every content read independently validates its target, traverses
relative components with descriptor-based no-follow opens, checks for a regular
file and reads from the checked descriptor. Symlink replacement after discovery
or after resolution therefore cannot redirect the content read outside the root.
Nonblocking opens prevent FIFO reads from hanging before the regular-file check.
All opened descriptors are closed on success, failure and early return.

Ordinary nested files, in-root file symlinks, explicitly selected root aliases and
original source anchors remain supported. Explicit `--files` selection is
unchanged: users must still select appropriate paths and avoid sensitive data.

The selected root, its alias binding and its ancestors are trusted during root
acquisition. This is not a filesystem sandbox against hard links, mounts,
concurrent content modification, resource exhaustion or hostile relocation of
already-open directories. Platforms without descriptor-relative no-follow opens,
including Windows, skip automatic content searches and log a warning. Ordinary
zero-hit evidence reporting remains, so operators must inspect that diagnostic;
zero hits do not establish that a security search ran. Native Windows behavior
has not been tested.

## Dependency Requirements

Lock-only changes do not protect ordinary pip installations. Published base
requirements now enforce `anyio>=4.14.2` and `certifi>=2026.10.19`. The `gemini`,
`google` and `vertex` extras enforce `urllib3>=2.8.0`; `all` inherits the floor.
Base-only installs do not gain an otherwise unnecessary urllib3 dependency.
These requirements do not protect installations that disable dependency handling.

The AnyIO and urllib3 dependency branches are integrated. Current compatible
stable lock resolutions are AnyIO 4.15.1, certifi 2026.10.23, urllib3 2.8.0 and
typing-extensions 4.16.0, the last required by current AnyIO. Unrelated locked
package versions are unchanged.

Confirmed affected locked versions and upstream fixes:

| Dependency | Previous Lock | Required Floor | Advisories |
| --- | --- | --- | --- |
| AnyIO | 4.12.0 | 4.14.2 | [TLS hostname handling](https://github.com/agronholm/anyio/security/advisories/GHSA-82r6-8w77-94w6), [process-pool deadlock](https://github.com/agronholm/anyio/security/advisories/GHSA-5p39-cfhj-2xmp) |
| urllib3 | 2.7.0 | 2.8.0 | [proxy TLS](https://github.com/urllib3/urllib3/security/advisories/GHSA-8988-9cw3-xx77), [Deflate loop](https://github.com/urllib3/urllib3/security/advisories/GHSA-gh4c-6fx4-qh6g), [chunk-size allocation](https://github.com/urllib3/urllib3/security/advisories/GHSA-vxq7-64xx-v4gw) |
| certifi | 2025.11.12 | 2026.10.19 | [emSign chain trust](https://github.com/advisories/GHSA-6q48-6c7w-9gw2) |

Certifi 2026.10.18 was the first upstream repair; the
[Python security announcement](https://discuss.python.org/t/information-for-python-users-regarding-emudhra-emsign-ca-certificate-security-incident/109576)
recommends 2026.10.19 to preserve unaffected roots. The floor follows that
recommendation, not a claim that 2026.10.18 retains the compromised root.
These are dependency-version matches, not proof of exploitation in Council.

## Verification

- Before the fix, five containment regressions demonstrated outside marker delivery
  and unchecked reads. Added tests also exposed missing safe-open enforcement and
  blocking FIFO behavior. No test sent an outside marker to a live provider.
- Final containment regression file: 17 passing cases. Existing evidence tests plus
  containment: 23 passed. Independent security inspection approved the scoped fix.
- Locked environment: 1,293 passed, 52 opt-in native tests skipped.
  The skipped tests are not passes. Existing SDK and multiprocessing deprecation
  warnings remain; no native-provider behavioral certification is implied.
- Fresh wheel with current resolver-selected `[all,dev]` dependencies: 1,293 passed,
  52 skipped. All 67 installed package files match the wheel. Dependency consistency
  checks pass. Six real resolver-conflict checks reject the vulnerable AnyIO and
  certifi versions in base, and urllib3 in Gemini/Google/Vertex/all installs.
- Ruff lint/format, strict mypy and lock consistency checks pass. Vulture retains
  18 unchanged baseline findings outside this patch; no dead-code cleanup is claimed.
- Test runtime: Python 3.12.15, OpenSSL 3.5.9; isolated build backend Hatchling 1.32.4.
  The runtime is at the checked vendor patch levels, not a whole-host security
  clearance. Apple system Expat/zlib backport applicability remains unverified.

Advisory checks use public package names, exact versions and ecosystems only.
Same-day unchanged-version results are reused; new versions are checked against
OSV and upstream advisories. Fresh CVE Now connectivity failed with TLS verification
enabled, and its prior certifi lookup/runtime feed lacked coverage. These are
unavailable checks, not clean results. No certificate verification was disabled.
Final catalog coverage and exact review/publication receipts belong in the GitHub
release record. Future dependency resolutions and deployment runtimes are not
certified by this candidate's tests.

Package/plugin versions, changelog, documentation and executable invocation examples
now require 0.8.5. Codex/native model policies, Gemini native-tool settings, Hermes,
personal configuration and existing client plugin caches are outside this release.
