# 0.8.11 Provider compatibility and output budgets

This release updates OpenAI model request compilation and Gemini 4 Argon and
Carbon structured output and thinking compatibility. Gemini 4 reasoning requests
use a 16,000-token default phase output cap in the default runtime profile; an
explicit token cap and the bounded profile retain their existing limits. The
larger cap can increase cost and does not guarantee a completed response.
The bounded profile keeps its lower cap; provider-default thinking may consume
output even when Council reasoning is disabled.

The execution plan records provider-specific budgets and attempt finish/usage
metadata. Review phases retain full evidence when it fits the existing estimated
input envelope; compaction and degradation remain visible when it does not.

The Google Gen AI SDK lock is refreshed for supported Python versions. SDK wire
tests use synthetic requests and a loopback transport; they do not prove live
provider acceptance, latency, or output quality. Provider timeouts and quota
failures can still occur, and successful fallback is not proof of a valid review.
