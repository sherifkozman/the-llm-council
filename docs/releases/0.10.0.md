# Council 0.10.0

Council can use Google's [Antigravity CLI](https://github.com/google-antigravity/antigravity-cli)
for a supplementary draft. Install `agy` separately using Google's instructions.
Council uses its ADC authentication in an isolated working directory.
[Google's headless ADC guide](https://antigravity.google/docs/enterprise/#adc-headless)
describes the credential and project requirements. The adapter needs an ADC file.
Set `GOOGLE_APPLICATION_CREDENTIALS` if the file is outside the standard location.

```bash
council doctor --deep --provider antigravity-cli --probe-timeout 30 --json
council run critic --mode review --reasoning-profile default \
  --providers vertex-ai,antigravity-cli \
  --models gemini-4-argon,gemini-4-argon \
  "Review this change" --files path/to/file.py
```

Include another provider for critique and synthesis. When Vertex and `agy`
both use Gemini, treat their drafts as one Google vote for review quorum.
Council requires a completed CLI response and checks its token totals. The
request timeout applies to `agy`, whose headless interface does not expose
a verified output-token cap. Vertex SDK generation and package dependencies
are unchanged.

The live qualification used Antigravity CLI 1.5.17 on macOS arm64. Check
readiness on each host after installing or upgrading the binary.
