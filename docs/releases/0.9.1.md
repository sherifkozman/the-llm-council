# Council 0.9.1

This release follows the changes described in the [0.9.0 notes](0.9.0.md).

- Python 3.10 `asyncio.TimeoutError` now triggers the same synthesis fallback
  as a built-in timeout, without retrying the same provider's schema path.
- For `z-ai/glm-5.2` through OpenRouter with high reasoning, default phase
  output ceilings are 32,768 tokens. Reasoning and visible output share this
  ceiling, so it can increase cost and latency. Explicit global or per-phase
  limits and the bounded runtime profile still take precedence. Bounded
  chunked drafts use a 900-token ceiling unless a global limit is set.
- The shared-login feed includes the exact Linux x86-64 Codex 0.167.2 runtime
  inventory and the four `gpt-6.1-sol` ChatGPT contexts tested with default or
  high reasoning and text or JSON-schema output. Other Linux builds and
  contexts remain unqualified and fail closed. The record shipped with a
  2026-11-28 expiry; later feed updates may supersede it.

The Linux record matches the artifact from [native platform CI run 43450992706](https://github.com/sherifkozman/the-llm-council/actions/runs/43450992706) for
the 0.9.0 candidate. The full qualification JSON SHA-256 is
`97eec80f637c937246134fcf0a80dbdcf1ad4c2b70d616226b7b00012aaf138d`.
The same synthetic adapter probe also passed in an
emulated x86-64 Linux container with Docker networking disabled. This does not
prove live authentication, every refresh race, or a match to a particular
machine's installed executable. Native global instructions remain inherited as
described in the 0.9.0 notes.
