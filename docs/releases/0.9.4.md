# Council 0.9.4

When a Vertex request stays in the local queue until the slot wait limit,
Council reports that it skipped the provider and sent no request. The
structured attempt record adds `error_category: provider_busy`. The existing
`error_type` field still reports the Python exception class.

If the other providers produce a usable result, the run can exit successfully
with `execution_status: degraded`. Report that status alongside the verdict and
check the required drafts and review quorum before accepting the result. The
[caller contract](../../skills/council/references/invocation-contract.md#result-read-sequence)
shows how to report the result from a shell or agent.

The release preserves the [0.9.3 Vertex deadlines and Codex compatibility
contexts](0.9.3.md). Dependency pins are unchanged.
