# Council 0.9.6

Council requires Pydantic 2.14.4 or later, which includes the fixes for
[CVE-2026-133429](https://github.com/pydantic/pydantic/security/advisories/GHSA-qpmf-fgh3-ff25)
and [CVE-2026-133424](https://github.com/pydantic/pydantic/security/advisories/GHSA-3r8g-cqwr-jr29).

The Google provider extras require websockets 17.4 or later on Python 3.11
and later. This includes the fix for
[GHSA-6m5v-9gmr-5665](https://github.com/python-websockets/websockets/security/advisories/GHSA-6m5v-9gmr-5665).
Python 3.10 is still supported. The Google extras on that version still
resolve a websockets release in the advisory's affected range. Use
Python 3.11 or later to install the patched websockets release.

The locked Google Gen AI SDK stays at 3.3.0 on Python 3.11 and later.
Council's Vertex path continues to use `generateContent` with its existing limits.
